# 工作风格：按主线节奏推进，不沉迷细节

**Why**：2026-08-18 用户在交互样张反复打磨（磁吸手感、右键菜单、双模式拖拽）期间明确纠偏：「别太沉迷于细节，按主线节奏推进」——样张是验证工具不是交付物，细节像素按 mainline §7 分层原则留集成验收收口。用户决策风格务实：中途改主意直接说（如「我改变主意了，希望用右键菜单」）、接受无默认档这类省事折中、愿意 11 项一次性按推荐冻结。

**How to apply**：
- 每轮工作先对齐「当前在 mainline §6 哪个阶段门、本动作是否推进它」；样张/视觉打磨够用即停，主动往下一阶段门引。
- 收口类问题给推荐项 + 允许「全按推荐冻结」式一次性拍板，别把用户拖进逐项像素讨论。
- 用户说「保持这样即可」时尊重现状（如无默认拖拽档），不主动加回默认行为。
