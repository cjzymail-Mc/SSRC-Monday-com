# 人机分诊 + agent 主动巡检（2026-08-25 首跑，08-27 固化）

**分诊判据**（不是「能否写自动化测试」，而是「用户尚未表达偏好前，agent 能否仅凭现有合同和客观证据判定它是 Bug」）：

- 只能人工拍板：无唯一客观正确值（蒙版透明度、动画手感、信息密度、布局空间分配）。
- agent 可自主判定：有可计算不变量/既有合同/可重复事件结果（标签重叠、层级坐标、状态应保持、入口可达性）。
- 人机协同：agent 能发现不一致或入口扩散，首次定方向需用户拍板；拍板后回归可完全自动化。

**巡检方法**：静态查 DOM/CSS/事件状态机＋与生产同构的隔离临时库起服务＋真实 Chromium 多视口实测；产出 AUD-NN（证据/根因/影响/建议修复＋建议验收），**逐项等用户授权再施工**——AUD-03 窄屏导航停在 PENDING_HUMAN_REVIEW 是范例不是例外。不写真实库，探针脚本用后即删。

**Why**：单轮实跑抓到 2 个真 bug（滚轮锚点日期漂移 4 天、撤销按钮 Tab 45 次不可达）＋1 待审；用户原话钦定回路：「接下来你主动进行自主排查……我审核通过后再执行」「AUD-01 - AUD-02 先修复」。

**How to apply**：每轮体验修复收口后跑一次；不是每轮默认全量（巡检有真实浏览器/临时库成本）。实例指针：repo 根 `GATE5-UX-BUGFIX-20260825-20260826.md` §8 分诊表/§9 AUD 记录，不复制正文。
