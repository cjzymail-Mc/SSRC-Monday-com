# 决策覆盖留痕四层规则（2026-08-14 ~ 10-09 跨三切片 13 处稳定实践）

1. **覆盖注记**：新拍板覆盖旧决策时在原处留显式注记（以注记为准），历史凝固态不改写。
2. **追加式留痕**：返工/失败/failure key 记录追加写入，不回写抹除。
3. **证据目录不覆盖**：每轮迭代的基线、日志、截图、diff、哈希清单放独立目录，不覆盖历史轮次。
4. **as-built 防复活**：关键 as-built 结论及时蒸馏回主线文档，防冷会话从早期问卷/旧文档复活已停用入口或视角。
