# 交互几何计算真源（2026-08-26 AUD-01 ＋ 08-27 缩放居中修复，两实例同根因）

- **坑 1｜硬编码布局常量**：wheel 缩放锚点用 JS 写死 `leftWidth=220`，实际非时间区 334px（`.timeline-e-axis` 左缘 607 vs 滚动容器左缘 273）——鼠标下的日期单次缩放漂移 4 天（09-13→09-17），手感是「画布向一侧滑走」。修法：wheel 发生时用实际元素实时 `getBoundingClientRect()` 重算左/右非时间区与有效时间宽度。
- **坑 2｜锚点读内存旧值**：缩放中心读 filter 里的旧 center，而全屏/边界夹取后真值已变——表现为「缩放时今天轴自动居中、画面漂移」。修法：以当前已渲染的 `data-viewport-center` 为真源。
- **边界**：事件时测量、布局变更即失效缓存——不是每帧测量（性能代价），别机械照抄成本能。
- **判定信号**：「鼠标锚点漂移」「缩放时画布滑走/自动居中」类 bug ＝ 坐标系不共享真源。与 browser-event-order-testing 互补：那张卡管测试诊断（用 rect 探针），本卡管实现纪律（别产生要靠探针才能发现的漂移）。
