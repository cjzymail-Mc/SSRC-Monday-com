# 保存可靠性三件套（2026-10-22~10-29 时间轴批次定型，真实并发会话验证）

- **409 版本冲突**：保留用户本地输入并采纳最新项目版本，由用户显式确认最新值与待提交修改后才重试；绝不自动重试、不顺带提交同项目其他草稿。
- **保存进行中**：锁定重复提交、取消与离页。
- **普通失败（500）**：恢复后可重试，失败保留输入。
- **净变更检测**：无实际改动不发起保存。
- 多入口（五时间轴入口/批量编辑器）统一同一冲突语义，并有真实并发会话验证。
