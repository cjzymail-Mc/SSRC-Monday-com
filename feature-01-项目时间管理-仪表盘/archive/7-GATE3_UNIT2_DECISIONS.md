## E7d · 一次拖了两个节点，中间的节点跟谁走（多锚点分段平移细则）

**这题在问什么**：你拍过的顺延规则是「改 B 日期 → B 之后的整体平移、间隔保持」。那**同一批**里改了 B 和 C 两个节点呢？B 和 C 之间的节点听谁的？这是冻结规则没覆盖到的新情况，需要补一条细则。

**举个例子**：主线 A→B→C→D（日期 8-01 / 8-10 / 8-20 / 8-30）。你同批把 B 拖到 8-12（+2 天）、C 拖到 8-25（+5 天）。B 和 C 之间的间隔怎么算？

- **推荐规则（钉住 + 分段平移）**：B、C 钉死你给的新日期；B~C 之间若有节点，跟随**离它最近的上游锚点**平移——本例 B~C 之间没有节点，D 跟 C 平移 +5 → 8-30 变 10-04；每个锚点段内部「相对间隔不变」。
- 换个有中间节点的例子：A→B→X→C→D，B +2、C +5：X 在 B 和 C 之间 → 跟 B 平移 +2。直觉：**你亲手钉住的钉子不动，每两颗钉子之间的相对节奏保持原样**。

**【你的回答 — 选一个】**

- [√] **A. 钉住 + 分段平移（推荐）**：direct 节点钉住新日期；每个非 direct 节点跟随最近上游 direct 节点的位移整体平移。**推荐理由**：这是你已拍的单锚点规则（后续整体平移、间隔保持）在多锚点下的自然推广——每两颗钉子之间间隔保持不变；算法无歧义、可预测。

## P2 · 七项高置信项打包确认（E2 / E3 / E3b / E5 / E6 / E7a / E8）

**这题在问什么**：以下七项 planner 置信度高、有代码先例或你已拍的条款直接支撑，属于「实现层怎么落」，打包请你过目——大白话版：
