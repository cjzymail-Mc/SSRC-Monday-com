三种方案，解决三个不同的问题

参考 7.png 的分组表格和彩色列，但沿用 Flowboard 的“项目 → 阶段 → 单日期节点”工作方式。当前推荐 A，B 与 C 用来比较侧重点。

A · 主表 / 近期节点　推荐

一行一个节点，按“本周节点 / 下周预览”分组，保留参考图的主表布局。适合每天开工前快速扫一眼，明确哪件事该推进。

可隐藏已完成，只看待推进节点；逾期节点使用红色状态格。
B · 项目进展摘要

一行一个项目，显示当前筛选内的临近节点、逾期数量，以及全项目节点完成比例。适合负责人做跨项目检查。

代价：节点细节折叠，仍需点开查看。
C · 阶段工作台

仍是一行一个节点，按现有六阶段分组。适合例会时集中查看测试、量产等阶段的近期节点。

分组体现节点所属阶段，不等于项目当前阶段。

如何融入当前系统入口设为“我的工作 → 近期工作”。此页用于清单预览，本周 / 本月继续提供日历时间轴视角；不取代时间表编辑器。默认仅预览，点击名称后可进入对应项目。

保留已有业务语义创建人是项目创建人，不是新增任务负责人。状态只使用已完成与日期派生的今天 / 待办 / 逾期；不新增优先级或进行中字段。节点只显示单日期；B 的横条仅表示已完成节点占比。

值得先讨论的两个选择更常用“我的项目”，还是“团队项目”？需要看到每一条近期节点，还是更关心每个项目的下一件事？先确定这两点，再决定 A 或 B。

这份样张可以体验什么方案切换、项目范围、日期筛选、创建人筛选、搜索、显示完成项、折叠分组、点击节点 / 项目详情。所有数据均为本地虚构示意；不会读取或提交业务数据。
