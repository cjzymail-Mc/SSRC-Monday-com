# Feature 03：样鞋下单系统

本目录集中保存样鞋下单功能的交付材料。`集成源码/` 按仓库原有路径保存本次涉及的 14 个文件。一次性的校验清单、补丁和临时产物放在已加入 Git ignore 的 `过程文件/` 中，不进入 Git。

## 在 Flowboard 中运行

仓库根目录和 `flowboard/` 下的同名文件是当前运行源码。本目录的 `集成源码/` 是这些文件的交付快照，不能单独启动。今后若修改样鞋下单功能，需要同步更新运行源码与本目录快照，或从本目录将对应文件复制回仓库原路径后验证。

登录 Flowboard 后，从左侧菜单进入“样鞋下单”，或打开 `/sample-orders.html`。订单、图片和扫描件保存在 Flowboard 的本机 SQLite 数据库及附件目录中，供同一工作区成员查阅。数据库结构升至 v21；正式环境更新时应使用仓库原有的备份与升级流程。

## 功能范围

- 录入多款样鞋需求，鞋款级选择先锋、外协、大货；可复制鞋款明细。
- 制表人从六个固定姓名中选择；记录交接状态和接收人。
- 按原签字模板导出 Excel，按实际鞋款生成行数；承接单位不写入签字表。
- 上传鞋款图片与签字扫描件，查看需求单，按年度导出统计。
- 页面采用深蓝、正红、亮黄配色。不包含工艺单 OCR，也不需要 OCR 安装包。
