# Excel 模板与导出格式统一（2026-09-16）

## 授权范围

用户确认暂不需要多个 Excel 文件的批量导入，要求先实现统一模板与导出格式；同时确认一个 Excel 内的多项目导入已支持。本轮保持单文件、首个数据表、按项目名称创建项目的流程。

## 实现

- `flowboard/timeline_excel.py`：新增时间表专用生成器。空白模板和实际导出共用七列表头、样式、列宽、冻结首行、筛选、日期格式、下拉校验和填写说明；沿用原填写模板的深蓝表头、主线浅蓝/并行浅绿布局。轨道和状态颜色使用条件格式，随填写内容更新。
- 日期使用 Excel 数值单元格及 `yyyy-mm-dd` 格式；超出既有数值日期导入范围的合法文本日期仍以文本导出，避免改变原有可往返日期范围。
- 空模板第一张 Timeline 表不预填示例；两个项目的示例只位于第二张填写说明表。预填 300 行格式，校验与条件格式覆盖 1000 行；实际导出超过 300 行时按数据扩展。项目名称长度校验与服务端对齐为 200 字，节点和备注为 500 字。
- `flowboard/timeline.py`：时间表导出改用共享生成器；提供权限相同的空模板读取；空白模板上传返回 `IMPORT_EMPTY`，不生成零行导入批次。
- `server.py`：新增 `POST /api/workspaces/{id}/timeline/template`，沿用登录、CSRF 和工作区成员权限，并返回真实 XLSX、文件名和 SHA-256。无数据库结构或数据迁移。
- `timeline-ui.js`、`app.js`、`timeline.css`：导入窗口加入“下载标准模板”，保留导入预览。模板校验失败只显示下载错误，不撤销已通过的导入预览；关闭弹窗后不会由过时请求触发下载。说明一个文件可含多个项目、旧八列兼容及同名项目不能覆盖。
- `index.html`：更新本次变更资源的版本参数。`README.md`：记录当前入口和文件约定。
- 通用看板 `make_xlsx` 不变；原两份填写模板作为历史兼容输入保留。当前标准模板以应用下载入口为准，避免另维护一份会与服务端漂移的静态文件。
