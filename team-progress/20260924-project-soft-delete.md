# 项目软删除入口与权限（2026-09-24）

用户在隔离浏览器中要求：单项目仪表盘【项目操作】菜单增加【删除项目】；管理员和项目创建者均可删除；已归档项目也可在【已归档】列表直接删除，无需先取消归档。本次覆盖旧“仅管理员软删”和“归档后先取消归档再删除”的限制，已同步到当前主线与归档合同。

实现复用现有 `DELETE /api/workspaces/{id}/timeline/projects/{project_id}`。服务端继续校验 workspace、角色、创建者、项目版本和未删除状态；允许归档项目软删除，保留项目行、节点、`archived_at` 与先前审计。新 `timeline.project_deleted` 审计包含操作者、时间、项目，以及删除前后版本、原归档时间和删除时间。UI 在单项目菜单、我的项目行和已归档列表按管理员或创建者权限显示删除；删除前明确提示软删除、历史保留和暂无网页恢复入口。有本地草稿时提示会丢失，提交成功才清理该项目草稿；从归档列表删除后仍停留该页。
