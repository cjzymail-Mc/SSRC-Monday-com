## 直接体验

[8083 隔离体验页](http://127.0.0.1:8083/)，管理员 `test / test`，普通成员 `u2 / localtest`。侧栏进入「项目概览」即可查看完整项目。首次概览为全部项目、全部日期、全部节点，当前37项目/314节点；其中30个真实结构演示样本为300节点。统计是动态快照。

简短体验路线：

1. 在项目概览点「需关注 / 逾期 / 今日 / 已完成」，再切「我的项目」。项目进度保持按完整项目计算，展开显示当前命中节点。
2. 点「筛选」选择项目标签（跑步与训练、球类运动、休闲与户外，每类10个演示项目），可组合节点阶段、轨道、状态和搜索对象。切换后条件摘要保留，一键清除回到完整项目。
3. 搜索「晨曦休闲鞋 · 概念款」，展开查看21个节点、主线/并行、完整名称和备注；进入单项目或时间表，返回保留当前上下文。保存/撤销与草稿离页确认沿用原有路径。
4. 进入「项目时间轴」默认全部日期，侧栏子菜单切本周/本月；再次点击父菜单回到全部日期；回工作台仍可查看我的/团队项目及排序、导入导出和动态。标签管理与已归档仍独立可达，归档项目名称可直接进入只读单项目页并返回。

不必逐项人工找bug；本轮已自动走查主要旅程，用户最后确认整体菜单、切换和信息密度是否顺手即可。重新启动用本目录 `local-preview.cmd`，固定使用 `local-test-data/feature02-preview/flowboard.db`；正式库与8080未用于本轮验证。

## 用户现在能更顺畅完成什么

| 场景 | 之前 | 现在 |
| --- | --- | --- |
| 找到入口 | 7个侧栏业务/范围入口混排，概览再重复3个页签 | 5个模块；本周/月作为项目时间轴的子菜单，父菜单打开全部日期，概览重复导航移除 |
| 看完整项目 | 默认本周＋未完成，需要改日期与状态；21节点全完成项目被隐藏 | 首次概览直接完整显示，无额外筛选操作 |
| 切我的/全部项目 | 下拉选择，通常打开再选两步 | 两个归属按钮，一次点击 |
| 看逾期或完成事项 | 没有独立逾期/完成事项快捷条件；含已完成还混入未完成 | 节点快捷情境一次点击，命中口径与明细一致 |
| 按类型与低频条件筛选 | 常态5个下拉同时摊开，缺少类型/搜索对象区分 | 常态仅日期下拉；标签、阶段、轨道、节点状态、搜索对象按需展开 |
| 阅读主要信息 | 7列，头像/备注及长规则说明常驻 | 5列；创建者与备注进入展开，规则说明按需查看 |
| 判断进度 | 未完成筛选时进度常为0，容易误以为项目没进展 | 服务端完整项目进度稳定；展开另标显示节点数 / 总节点数 |
| 刷新与返回 | 刷新恢复默认，工作台团队页签及部分来源容易丢失 | 账户/工作区隔离的会话记忆；搜索不固化，当前页面刷新和下钻返回来源保留 |

取舍：低频高级条件多一步展开；本周/月由侧栏子菜单直接进入；点击“项目时间轴”始终打开全部日期。这样日期范围不再被误认成独立业务模块。原画布能力与权限不删减，不把表格的节点筛选等同于画布日期范围。

## 数据口径与授权边界

“我的项目”仍是创建关系。项目阶段、节点阶段不同；快捷筛选作用于节点，类型优先复用已有共享标签。完整项目进度由服务端计算，原筛选进度字段为兼容保留但不作为概览行进度。下一未完成仍取全项目最早未完成日期，同日节点在展开处完整可查。

无schema迁移、无新任务实体、无框架/外部服务。新增筛选参数严格校验，继续在查询前鉴权，排除归档/软删项目及软删节点；未知/停用/跨工作区标签拒绝，不泄露名称。未分类只认当前工作区活跃标签关系。查看不授予编辑权限，原版本、审计和草稿链保留。

演示库增加3个共享分类标签，每类10项目；新增前SQLite backup完整性ok，节点表全量哈希前后相同，详见 `demo-tags.json`。只重启经进程路径核验的8083隔离服务加载新只读投影。未写/迁移正式库、未重启正式服务、未commit/push/部署、未改变机器配置。
